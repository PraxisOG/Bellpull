KokoroPhonemizer.kt adapts English dictionary lookup and inflection rules to Kotlin;
normalization, bounded phrase splitting and JNI integration are Bellpull code.
It uses default heteronym pronunciations without a part-of-speech tagger.

These model/dictionary components are Apache-2.0, reproduced in
Apache-Misaki-Kokoro.txt. Weights are downloaded separately, pinned and hash checked.
No eSpeak, Piper phonemizer, Python runtime or system speech service is bundled
for Kokoro. Inference uses the existing isolated ONNX Runtime (MIT) CPU library.
