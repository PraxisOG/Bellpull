# Bellpull plugin 0.9.26 experimental

On a full stock Hermes 0.23.4 gateway, **Coding activity** now shows Codex and Claude Code processes started by a personal chat. Each entry identifies the original Hermes run and child process. Opening the panel or reconnecting reads that same task.

The native Stop action can cancel the Hermes parent while the coding process continues. Coding activity reports the child’s observed state and exit outcome independently.

This release includes signed Android 0.20.26 experimental, build 76.
