Bellpull README images — version 0.3.3

bellpull-icon.png is an unchanged copy of the app icon in
android/app/src/main/res/drawable-nodpi/bellpull_icon.png.

GUI images are unchanged copies of verified Roborazzi screenshot baselines
rendered from the app composables with fictional conversations and example URLs.
The black circle in unfolded-maroon.png simulates the unfolded camera cutout.
These are rendered app screenshots, not photographs of a physical device.
No personal chats, credentials, live server data or phone captures are included.
