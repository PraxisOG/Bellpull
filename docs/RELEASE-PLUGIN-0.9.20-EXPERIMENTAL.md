# Bellpull plugin 0.9.20 experimental

On stock Hermes 0.23.4, opening Coding activity previously returned HTTP 404 even when Hermes had recorded the executor. Android and Desktop can now read the original run, process, executor session, output and workspace changes. Reopening a chat uses the existing run.

The plugin reads the selected profile’s native compression lineage. Forks, delegated chats and resets keep their own activity. Hermes 0.21.5 continues to use its legacy session database.

This release includes signed Android 0.20.22 build 72. Interactive executor approvals still require a connection from the gateway to the executor.
