# Bellpull 0.20.32 experimental · Shared Canvas property drafts

Android keeps the text and dimensions you are editing when another client saves the same object. If a property changed on both clients, the inspector shows its saved value and lets you keep that value or apply your edits. Saving sends only changed properties and preserves fractional dimensions on the object.

This release includes signed Android build 82 and server plugin 0.9.27-mobile-preview. [Shared Canvas tracker](https://github.com/PraxisOG/Bellpull/issues/38)
