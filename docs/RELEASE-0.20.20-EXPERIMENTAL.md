# Bellpull 0.20.20 experimental · Stop a Desktop coding run from Android

Open the same conversation on Android, choose **Coding activity**, and tap **Stop this Hermes run** on a running task. The phone checks the parent run ID and its original chat with Hermes. The stop applies to that whole run, including any coding processes it owns.

Build 70 uses the same server plugin as build 69, **0.9.14-mobile-preview**. [Coding activity tracker](https://github.com/PraxisOG/Bellpull/issues/43)
