# Bellpull 0.20.24 experimental · Voice on the built-in speaker

Unplugging an unused headset can trigger a system-wide headphone warning. Build 74 keeps a voice conversation listening when Android confirms the same built-in speaker is still selected. Disconnecting the headset that Bellpull is using still pauses voice and requires Resume.

This release includes Android build 74 and server plugin 0.9.22-mobile-preview. The original wired Android Auto report remains open. [Voice interruption tracker](https://github.com/PraxisOG/Bellpull/issues/3)
