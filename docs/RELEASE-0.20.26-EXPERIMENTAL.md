# Bellpull 0.20.26 experimental · Review approvals on Hermes 0.23.4

Stock Hermes 0.23.4 can pause a run with its approval in a list of pending controls. Build 75 missed that prompt. Build 76 shows it in the conversation and the Today approval queue. A spoken or tapped decision applies to the exact prompt and execution you reviewed. Bellpull checks the host’s receipt before reporting that your decision succeeded.

This release includes Android build 76 and server plugin 0.9.22-mobile-preview. [Approval tracker](https://github.com/PraxisOG/Bellpull/issues/37)
