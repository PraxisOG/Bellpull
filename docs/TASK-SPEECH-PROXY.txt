Bellpull task: move the offload speech pipeline (STT + TTS) behind the bellpull plugin so the app never talks to a second server or key. The plugin proxies to a loopback helper process on the same host; the helper itself is out of scope for this repo.

Contract (docs/hermes-api.md is the source of truth — you must add this section there):
- GET  /api/bellpull/speech/health -> {ok, tts, stt, tts_loaded, stt_loaded, proxy:true} plus latency probe optional
- POST /api/bellpull/speech/tts   JSON {text (1..4000 chars), voice?, stream?} -> audio/wav (48kHz stereo) or, when stream=true, chunked 16-bit little-endian mono PCM at 48kHz. Pass through X-Audio-Seconds and X-Took-Ms headers when present.
- POST /api/bellpull/speech/stt   multipart field "audio" -> {text, language, seconds, took_ms}
All three use the same bearer auth as every other bellpull route (adapter._check_auth, same as capabilities). 503 with a JSON error when the helper is unreachable; 504 on timeout (tts 120s, stt 60s). Add "bellpull_speech": <bool> to the capabilities features map (true when the proxy module is wired).
