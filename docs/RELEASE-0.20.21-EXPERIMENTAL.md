# Bellpull 0.20.21 experimental · Coding history across tasks

When multiple coding tasks share a chat, **Coding activity** shows the latest 300 output records. With plugin **0.9.15-mobile-preview**, the panel tells you when earlier records fall outside that window, including after you close and reopen the chat. Build 71 can also detect when an incremental update from an older plugin displaces an earlier record.

Updates to an existing record keep its place in the history limit. Each task keeps its original run identity and recorded outcome. [Coding activity tracker](https://github.com/PraxisOG/Bellpull/issues/43)
