# Bellpull 0.20.28 experimental · Unknown run recovery

After an abrupt gateway shutdown, Hermes can retain a run’s identity while losing its outcome. Build 77 kept displaying “Working…” and offered Stop for that run. Build 78 explains the uncertainty in the original chat, clears stale controls and keeps the saved request. **Check status** reads the same run again after review in Hermes. When Hermes supplies an active or final state, Bellpull resumes tracking that run or loads its saved result.

This release includes signed Android build 78 and server plugin 0.9.26-mobile-preview. [Coding activity tracker](https://github.com/PraxisOG/Bellpull/issues/43)
