# Bellpull plugin 0.9.24 experimental

On stock Hermes 0.23.4, Android shows when an admitted chat run switches providers. Each transition identifies the previous and current model. When Hermes knows whether the new model accepts images, Android shows that capability alongside the switch.

Open **Message info** on a completed text reply to see the model and provider that answered. Bellpull can recover this evidence after reconnecting or restarting the gateway while Hermes retains the original keyed submission.

This release includes signed Android 0.20.26 experimental, build 76.
