# Bellpull 0.20.33 experimental · Background worker answers

Android shows the worker’s answer in the original chat when Hermes saves a recognized single-worker completion. Read-aloud and text selection use the same answer. Failure details and partial output remain visible. Android shows unfamiliar or ambiguous reports in full.

This release includes signed Android build 83 and server plugin 0.9.27-mobile-preview. Stock Hermes 0.23.4 can still exhaust its delivery attempts while the chat is busy. [Worker delivery tracker](https://github.com/PraxisOG/Bellpull/issues/51)
