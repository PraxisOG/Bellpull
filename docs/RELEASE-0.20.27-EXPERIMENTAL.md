# Bellpull 0.20.27 experimental · Calendar account availability

Build 76 could report a confirmed empty calendar when a selected account disappeared from Android. Build 77 shows the missing selection in Today and Calendar. Events from available calendars remain visible. When Hermes is reachable, Bellpull clears the prior shared planning read. Confirmation resumes after all selected calendars return or you remove the unavailable calendars from the selection.

This release includes Android build 77 and server plugin 0.9.26-mobile-preview. [Calendar reliability tracker](https://github.com/PraxisOG/Bellpull/issues/28)
