# Bellpull 0.20.31 experimental · Dictation keyboard controls

When Bellpull Dictation first opened in another app with three-button navigation, Android could display its status line and leave both buttons with zero touch height. The keyboard now accounts for the navigation bar on its first measurement. It continues updating its padding when navigation changes.

This release includes signed Android build 81 and server plugin 0.9.27-mobile-preview. [System-wide dictation tracker](https://github.com/PraxisOG/Bellpull/issues/32)
